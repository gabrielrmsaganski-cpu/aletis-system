# Sincronização do servidor — 11/10/2026

O código em execução no servidor foi consolidado a partir da base `b66a460`,
que era a última versão disponível no GitHub. A sincronização preserva as
implementações locais de CRM, ALIX, portal, documentos, integrações fiscais,
planilhas, cálculos, interface e site institucional.

## Escopo e preservação

- Cópia do código anterior e bundle do histórico Git preservados no servidor.
- Nenhuma migração ou alteração de dados de produção nesta sincronização.
- Credenciais, documentos de clientes, evidências operacionais e arquivos
  gerados permanecem locais e fora desta publicação.
- O arquivo de dados de prospecção `socios-expansion.json` deixa de ser
  versionado; sua cópia operacional permanece no servidor.
- Senhas dos exemplos de ambiente foram removidas. O Docker Compose exige
  valores explícitos de senha no `.env`; o ambiente operacional foi preservado.
- Não houve atualização indiscriminada de versões de bibliotecas: o lockfile
  acompanha exatamente as melhorias já instaladas.

## Validação

- Instalação reproduzível com `pnpm install --offline --frozen-lockfile`.
- `pnpm typecheck`: aprovado em todos os workspaces que oferecem esse comando.
- Builds de knowledge-base, API, web e site institucional: aprovados.
- Os 223 arquivos do novo build web são idênticos, por SHA-256, aos arquivos
  correspondentes da versão já publicada. Não foi necessária nova implantação.
- Código da aplicação conferido contra a cópia operacional: sem divergências.
- Testes financeiros: 50 aprovados; testes contábeis: 35 aprovados.
- Testes de interface: 224 aprovados e 16 reprovados em 26 arquivos.
- Avaliação de confiabilidade da ALIX: reprovada no cenário de onboarding com
  evidência mínima de dívida total. O comportamento não foi alterado para
  contornar a avaliação.
- Suíte de API: 1.826 testes aprovados, 12 reprovados e 301 ignorados;
  218 arquivos aprovados, cinco reprovados e 25 ignorados. Um dos cinco
  arquivos falhou por indisponibilidade inicial da fixture PostgreSQL;
  após preparar o banco descartável, seus 38 testes passaram na reexecução.
- ALIX: conjunto anonimizado de 100 casos aprovado, avaliação de governança
  aprovada e 103 cenários Promptfoo aprovados. A avaliação de confiabilidade
  citada acima permanece reprovada.
- API, interface e site responderam HTTP 200 nas verificações locais.

As falhas de interface incluem continuidade de sessão da ALIX e componentes
de conexão fiscal. Os registros completos de validação permanecem na cópia
privada de evidências do servidor. Essas pendências precisam ser corrigidas
antes de declarar o sistema integralmente validado.

## Automação do GitHub

A atualização de `.github/workflows/ci.yml` permanece preservada no servidor,
mas o GitHub recusou seu envio porque o token OAuth conectado não possui
o escopo `workflow`. O restante do código foi sincronizado. A automação
existente no GitHub foi mantida, aguardando a ampliação dessa autorização.
